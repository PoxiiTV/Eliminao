# Changelog

## v1.0.1

### 🇪🇸 Novedades

- **Instalador más pulido:** botones sin bordes de foco, mensajes de error más claros (por ejemplo, si todavía no hay ninguna versión publicada) y compatible con lectores de pantalla
- **Primera actualización automática:** si tienes la v1.0.0, Discord te avisará para reiniciar y quedarte con esta

### 🇬🇧 What's new

- **Polished installer:** no focus borders on buttons, clearer error messages (for example, when no release has been published yet) and screen reader support
- **First automatic update:** if you have v1.0.0, Discord will prompt you to restart and switch to this one

## v1.0.0

### 🇪🇸 Novedades

**Primera versión de Eliminao**, mensajes temporales para Discord.

- **Botón de reloj** en la barra del chat con panel de ajuste rápido: atajos de tiempo, tiempo personalizado y modo *solo el siguiente mensaje*
- **Tiempo por chat, por servidor o global**
- **Atajo de teclado** configurable (`Alt+T` por defecto) y **prefijo** `!t 30s hola`
- **Cuenta atrás discreta** al final de cada mensaje temporal
- **Clic derecho** y **botón al pasar el ratón** para hacer temporal cualquier mensaje tuyo
- **Mis últimos N mensajes** y **selección múltiple** para borrar o hacer temporales varios de golpe
- **Instalador `.exe`** de un clic y **actualizaciones automáticas** desde GitHub

### 🇬🇧 What's new

**First release of Eliminao**, temporary messages for Discord.

- **Clock button** in the chat bar with a quick settings panel: preset times, custom time and *next message only* mode
- **Per chat, per server or global timer**
- Configurable **keyboard shortcut** (`Alt+T` by default) and **prefix** `!t 30s hello`
- **Subtle countdown** at the end of every temporary message
- **Right-click** and **hover button** to make any of your messages temporary
- **My last N messages** and **multi-select** to delete or time several messages at once
- One-click **`.exe` installer** and **automatic updates** from GitHub
